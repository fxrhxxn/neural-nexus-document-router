# Neural Nexus Document Router

MA6700 Applied AI and Machine Learning — Assignment 3

## Project

Automatic Routing of Scanned Incoming Documents for a Government Registry

## Team

- Farhaan Hassam — Team Leader / Data Pipeline
- Christa Mungada — Preprocessing, OCR & Baseline
- Parisha Chooromonay — Deep Learning & Architecture
- Uddish Reetoo — Evaluation, Thresholding & Demo

## Python Version

Python 3.11

## Setup

Clone the repository:

git clone <repo-url>

Create a virtual environment:

Windows:
python -m venv .venv
.venv\Scripts\activate

macOS:
python3 -m venv .venv
source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt
