## Setup

Clone the repository:

git clone <repo-url>

Create a virtual environment:

Windows:
python -m venv .venv
.venv\Scripts\activate

macOS:
python3 -m venv .venv
source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt
